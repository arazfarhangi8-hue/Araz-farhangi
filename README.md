# Araz Media
سامانه مدیرمحور آپلود ویدیو و ساخت QR Code؛ بیننده با اسکن QR صفحه پخش و توضیحات را می‌بیند.

## راه‌اندازی لازم
این سایت به Firebase نیاز دارد؛ GitHub Pages فقط فایل‌های سایت را میزبانی می‌کند و محل ذخیره امن فایل‌های آپلودی نیست.

1. در Firebase یک پروژه بسازید و برنامه Web اضافه کنید.
2. در Authentication، روش Email/Password را فعال و حساب مدیر را ایجاد کنید. حساب عمومی نسازید.
3. Firestore Database و Storage را فعال کنید.
4. محتوای فایل firebase-config.example.js را در فایل firebase-config.js کپی و مقادیر واقعی پروژه را جایگزین کنید.
5. محتوای firestore.rules را در Firestore Rules و storage.rules را در Storage Rules منتشر کنید.
6. در تنظیمات Authentication > Settings > Authorized domains دامنه GitHub Pages این سایت را اضافه کنید.
7. در مخزن GitHub، Settings > Pages را روی Deploy from a branch و شاخه main / پوشه root قرار دهید.

## رفتار QR
اعتبارهای قابل انتخاب: همیشه یا ۱ تا ۷ روز. تاریخ انقضا در Firestore ذخیره می‌شود و صفحه تماشا پس از انقضا ویدیو را نمایش نمی‌دهد. QR در مرورگر به PNG ذخیره می‌شود.

## نکات مهم
- حساب مدیر باید فقط توسط مالک ساخته شود.
- فایل‌های ویدیویی عمومی‌اند تا QR بدون ورود کار کند؛ هرکس لینک را داشته باشد می‌تواند آن را ببیند.
- حذف خودکار فایل منقضی‌شده در این نسخه فعال نیست؛ فقط نمایش آن مسدود می‌شود. برای پاک‌سازی خودکار Storage به Cloud Function زمان‌بندی‌شده نیاز است.
- سقف رابط فعلی ۵۰۰ مگابایت است؛ محدودیت‌های واقعی Firebase و هزینه‌های Storage/دانلود نیز اعمال می‌شود.
- قبل از انتشار عمومی، قوانین دسترسی و تنظیمات صورتحساب Firebase را بررسی کنید.
